# Data layout

- Put the six challenge data files in `raw/challenge/` without modifying them.
- Keep the official starter notebook in `../notebooks/reference/` if it is part of the project.
- Downloaded weather/external datasets go under `external/<source>/` with a manifest and source licence record.
- Processed timelines and feature matrices go under `processed/` and are generated, not hand-edited.
- Never commit secrets. Raw challenge inputs may remain committed if permitted under the challenge data licence; generated external data is not automatically safe to redistribute.
