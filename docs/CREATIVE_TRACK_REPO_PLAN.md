## Evidence policy

TASK008 supplies current P_fix forecasts and genuine retrospectively generated OOF predictions. It does not supply hidden private actuals, archived operational first-publication data or independent probability calibration. Interval end is an availability proxy; historical confirmation has prior analyst exposure. Match evidence by station/duration/lead and report origins as well as overlapping decision counts.

Core demo needs no external weather, air-quality or map API. Add ClimateVerse data only after per-dataset licence, terms and availability review.
