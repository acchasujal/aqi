# EXP-012 forecast task audit

Snapshot: 47,849 labelled Train rows from 2025-02-19 02:00 through 2026-11-02 22:00 target-hour start (IST); latest observed interval ends `2026-11-02T23:00:00+05:30` at all four stations. Test has 2,592 rows, 648 per station, with target starts from 2026-10-22 through 2026-11-20. Four station IDs are 11606, 11611, 3409510 and 3409511. The announced private target window is November 11–12, 2026. Relative to the current PM cutoff, its starts are 193–240 elapsed hours ahead. The test grid also includes earlier dates, including dates before the current PM cutoff; those rows still require predictions for submission but do not all form valid prospective forecasts under this snapshot. The competition scoring subset is distinct from the full grid.

Train `timestamp_ist` marks observation interval **end**; `target_start` is that time minus one hour. Test `target_start_ist` is interval **start**, `target_end_ist` its end. Model run/issue time is distinct from PM cutoff; the reproducibility reference uses `2026-11-07T12:00:00+05:30` as model run time and the Train-derived PM cutoff above. Candidate PM features must use observations ending by the fold cutoff. The 2024 archive is a fixed prior predating all validation folds, but its source identity and hour-interval semantics remain unresolved. No future weather or auxiliary forecast features are available in the current inference pipeline.

Existing validation uses 48-hour target windows and nominal PM gaps 48/72/96/120 hours, seven-day fold spacing. It reproduces the private window length but not its current approximately 193–240-hour lead. EXP-012 includes a 192-hour diagnostic gap. The full 648-row-per-station test grid is not replicated by a 48-hour fold; scoring emphasis remains the announced 48-hour private period. No hidden targets or row-order features are used.
