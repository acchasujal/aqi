# EXP-015 W50 historical error decomposition

These are **historical validation** diagnostics from EXP-014's fixed target days and two issue regimes. They are not a decomposition of Zindi's unseen leaderboard labels. `scripts/audit_exp015.py` recomputes metrics from the ignored EXP-014 OOF cache; `ERROR_DIAGNOSTICS.json` contains every station, month, lead-day, target-hour, target-concentration bucket, and seasonal-availability group.

The huge full RMSE and negative average bias are generated by five extreme *unique* station-hours counted once in each regime. Ordinary-range behavior is more interpretable. W50 tends to overpredict lower concentrations: for `y ≤ 25`, public/private bias is +6.03/+11.85; for `25 < y ≤ 50`, +0.11/+6.15. It underpredicts polluted periods: for `50 < y ≤ 100`, bias −21.19/−24.39; for `100 < y ≤ 500`, −234.32/−238.14 across seven rows per regime. This is a regression-to-level pattern, but the seven high-range rows are too few to justify an untested bias correction. November bias is especially positive at the private horizon, so a generic upward correction could regress the actual target season.

Station-wise full private RMSE is Borivali 3956.61 (2 extreme rows), Malad 24.27, Byculla 195.51 (3 extremes), Shivaji Nagar 37.45. Corresponding public values are 3952.02, 17.45, 194.53, 32.70. Without the extreme rows, Borivali's diagnostic private RMSE is 16.35 and Byculla's 26.67. Malad and Shivaji have no `y ≥ 500` on these folds. The large hour-13/14 RMSEs are the Borivali spike, not a verified diurnal pattern.

Seasonal history is unavailable for 165/1,719 public and 163/1,711 private scored rows (about 9.6%/9.5%), triggering the documented recent-only fallback. On November rows it is absent for 100/430 and 98/426 (about 23%). All EXP-014 scored rows have an eligible recent component; these data do not test the seasonal-only branch. Seasonal-present groups contain the extreme events, so comparing their raw RMSE to seasonal-absent groups is confounded. Lead-day full RMSE is also confounded by the August spike: public days 1/2 = 2625.94/22.66, private lead days 9/10 = 2638.80/27.46. The ordinary-range metric and fold files must accompany any interpretation.

No hidden public labels were accessed. No target labels were filtered or clipped in full-target RMSE.
