# AQI Creative Strategy Add-on Pack

This add-on pack is designed for `acchasujal/aqi`. Copy the contents into the repository root, merging folders rather than replacing existing files.

It creates a separate creative-submission workstream for the Zindi Google Mumbai Data Challenge while preserving the existing forecasting/ML workstream.

## Files

- `docs/PRIZE_STRATEGY_AND_ELIGIBILITY.md` — award categories, dates, eligibility questions and submission checklist.
- `docs/REAL_WORLD_AIR_QUALITY_BENCHMARKS.md` — India and international systems, what they already do, and lessons for differentiation.
- `docs/CREATIVE_PRODUCT_SPEC_AIRWINDOW.md` — recommended product concept, users, MVP, requirements and non-goals.
- `docs/CREATIVE_JUDGING_AND_DEMO.md` — inferred judge rubric, demo structure and PDF contents.
- `docs/CREATIVE_DATA_AND_GOOGLE_TOOL_POLICY.md` — ClimateVerse, Google tool and licence/terms gates.
- `docs/CLAIMS_AND_USER_SAFETY.md` — scientific, spatial and health-claim guardrails.
- `docs/CREATIVE_TRACK_REPO_PLAN.md` — implementation order and repo structure.
- `prompts/CREATIVE_STRATEGY_AGENT_PROMPT.md` — master prompt for a repo-connected AI agent.
- `apps/airwindow/README.md` — creative app implementation contract.

## Important

The documents are a research-backed plan, not a claim that a product exists. Official scoring weights for the creative award are not published. Award stacking and undergraduate eligibility details require organiser confirmation. Dataset/API permissions must be checked before use.
